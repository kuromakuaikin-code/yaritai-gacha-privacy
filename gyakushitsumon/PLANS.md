# 逆質問ガチャ v1.0 リリース計画（自己完結版）

このファイルだけ読めば実装できるように書いてある。新規アプリ。`app-expo/`（婚活デートメモ）をコピーして作る。
目標: **9月中旬に審査提出 → 9月末公開**（10〜11月の転職求人の波に間に合わせる）。

## コンセプト（1行）

面接の最後の「何か質問はありますか？」で詰まらないための、逆質問の質問集＋ガチャ＋直前カンペ。

## なぜ成立するか（要約）

- App Store に逆質問特化アプリは存在しない（2026-07 確認。既存は AI 面接練習系＝回答側の練習のみ）
- doda が「逆質問 例文42点」「最終面接の逆質問 例文20選」を専用URL階層で展開しており、検索需要が実在する
- 一次/二次/最終 × 人事/現場/役員 で聞くべきことが変わる、という段階別の需要構造が各社記事で共通
- コンテンツ勝負 = 婚活デートメモ（52話題×200フレーズ）と同型の勝ち筋

## ⚠ スコープ規律（2〜4週間で出すための憲法）

- 画面は **4タブ（質問リスト / ガチャ / カンペ / 設定）だけ**。それ以外は作らない
- 企業別の管理・記録機能は **v1.0 では作らない**（跳ねたら v1.1 で婚活デートメモの Partners を移植）
- AI・通信機能なし。データは端末内のみ（AsyncStorage）
- 4週を超えそうなら機能を削って出す。削る優先順: 広告 → 無料/有料出し分け → ガチャ演出

## B. データ構造と全コンテンツ

```ts
export interface GyakuQuestion {
  id: string;
  text: string;   // そのまま口に出せる完全な質問文
  aim: string;    // この質問の狙い（1行）
}
export interface QCategory {
  key: string; emoji: string; name: string; free: boolean;
  questions: GyakuQuestion[];
}
```

質問文中の「〇〇」は企業名・面接官名・自分のスキルに置き換えて使う旨を UI に注記する。

### カテゴリA 🌱 一次面接 × 人事（a1〜a7・**free: true**）

- a1: 御社で活躍されている方に共通する特徴やスキルがあれば、教えていただけますでしょうか？｜aim: 活躍人材像＝評価基準を知る定番。答えに自分を寄せて自己PRに接続できる
- a2: 入社までに勉強しておくべきことや、準備しておくとよいことがあれば教えていただけますでしょうか？｜aim: 意欲を示す締め質問の定番。どの面接でも安全
- a3: 配属予定の部署は何名くらいの組織で、どのような年齢構成・雰囲気なのでしょうか？｜aim: 職場の実態を具体で聞く。ミスマッチ防止
- a4: 中途入社の方はどのくらいいらっしゃいますか？また、入社後はどのような研修やフォロー体制があるのでしょうか？｜aim: 中途の受け入れ体制を「制度」の形で確認
- a5: 御社の社風を一言で表すと、どのような言葉になりますでしょうか？｜aim: 面接官の答え方自体から文化が見える
- a6: 御社の評価制度では、どのような行動や成果が評価につながるのか教えていただけますでしょうか？｜aim: 給与の話をせずに処遇の仕組みを知る
- a7: このポジションの1日の仕事の流れについて、差し支えない範囲で教えていただけますでしょうか？｜aim: 求人票では分からない実務の解像度を上げる

### カテゴリB 🔧 一次面接 × 現場担当者（b1〜b6・free: false）

- b1: 配属予定のチームでは、現在どのような課題に取り組んでいらっしゃるのでしょうか？｜aim: 課題を聞く＝貢献の意思表示。答えは志望動機の材料になる
- b2: 入社した場合、最初に任せていただく仕事はどのような業務になるのでしょうか？｜aim: 入社後の具体イメージを双方で揃える
- b3: 〇〇様ご自身が、この仕事で最もやりがいを感じるのはどのような瞬間でしょうか？｜aim: 面接官個人に聞く型。場が和み、本音が出やすい
- b4: 業務を進めるうえで、他部署とはどのように連携されているのでしょうか？｜aim: 組織の風通し・仕事の進め方を探る
- b5: このポジションで成果を出すために、最も重要なスキルや姿勢は何だとお考えでしょうか？｜aim: 期待値を直接聞く。次の面接の対策情報にもなる
- b6: チームでは現在どのようなツールや進め方で業務をされているのか、教えていただけますでしょうか？｜aim: 実務レベルの解像度＋経験者アピールの入口

### カテゴリC 📈 二次面接 × 現場マネージャー（c1〜c7・free: false）

- c1: もしご縁をいただけた場合、入社後の最初の3カ月ではどのような成果を期待されますでしょうか？｜aim: 期待値のすり合わせ。入社意欲が強く伝わる定番
- c2: マネジメントをされるうえで、メンバーに対して大切にされていることは何でしょうか？｜aim: 直属上司になる人の価値観を知る
- c3: 部署として今後注力していく方針や目標があれば、教えていただけますでしょうか？｜aim: 部門戦略への関心を示す
- c4: これまで中途入社で活躍された方は、どのような点が優れていたのでしょうか？｜aim: 中途の成功パターンを聞き、自分の見せ方に使う
- c5: 私と同年代で活躍されている社員の方には、どのような共通点がありますでしょうか？｜aim: 自分の立ち位置を具体化する
- c6: 前職で培った〇〇の経験を活かしたいと考えておりますが、貴部署の業務ではどのような場面で活かせそうでしょうか？｜aim: 自己PRを質問の形でもう一度置く型
- c7: チームの目標達成に向けて、いま一番のボトルネックになっているのはどのような点でしょうか？｜aim: 課題解決者としての目線を示す。刺さる系

### カテゴリD 👑 最終面接 × 役員・社長（d1〜d7・free: false）

- d1: 中期経営計画で〇〇を掲げていらっしゃいますが、実現に向けて現場に最も期待されていることは何でしょうか？｜aim: 企業研究の深さを示す最終面接の王道。〇〇は要下調べ
- d2: 〇〇様がお考えになる、御社の一番の強みと今後の課題をお聞かせいただけますでしょうか？｜aim: 経営者の現状認識を聞く。回答から本気度が見える
- d3: 10年後、御社をどのような会社にしていきたいとお考えでしょうか？｜aim: ビジョンへの共感を確かめ、長期で働く意思を示す
- d4: 経営理念に〇〇を掲げていらっしゃいますが、日々の業務や意思決定ではどのように実践されているのでしょうか？｜aim: 理念が本物か形骸か、を丁寧に確かめる
- d5: 今後の事業展開の中で、私が配属される部門にはどのような役割を期待されていますでしょうか？｜aim: 自分の配属先を経営視点に接続する
- d6: 経営のお立場から見て、御社で長く活躍する社員に共通しているものは何だとお考えでしょうか？｜aim: 活躍人材像を最上位の視点で聞く
- d7: 業界では〇〇という変化が進んでいますが、御社としては今後どのように対応していくお考えでしょうか？｜aim: 業界理解を示す上級者向け。〇〇は要下調べ

### カテゴリE 🤝 全段階共通・締めの質問（e1〜e5・**free: true**）

- e1: 一日も早く戦力になりたいと考えておりますが、入社までに身につけておくべき知識やスキルがあれば教えていただけますでしょうか？｜aim: 最後の1問に置く定番。前向きに終われる
- e2: 御社で高い成果を上げている方は、入社後どのようなキャリアパスを歩まれているのでしょうか？｜aim: 長期で考えていることが伝わる
- e3: 仮に採用いただいた場合、配属先やミッションはどのように決まるのでしょうか？｜aim: 実務的な確認を意欲の文脈で聞く
- e4: 本日の面接を通じて、私にもし足りない点があると感じられたら、今後のためにぜひ教えていただけますでしょうか？｜aim: 度胸と素直さを同時に示す。印象に残る系
- e5: 将来的にはマネジメントにも挑戦したいと考えておりますが、御社ではどのようなステップでその機会がありますでしょうか？｜aim: 上昇志向を自然に示す

### NG集（ng1〜ng10・プレミアム。無料では ng1・ng2 だけ表示して導線にする）

各項目は `{ text, reason }`：

- ng1: 調べればすぐ分かることを聞く（事業内容・設立年など）｜企業研究不足＝志望度が低いと受け取られる
- ng2: 「特にありません」と答える｜関心・意欲がないと判断される最大のNG。最低2〜3個、消化に備えて5個用意する
- ng3: 待遇・条件（給与・残業・休日）の質問を最初から連発する｜条件優先の印象。聞くなら意欲を示した後に1つ
- ng4: 面接中に説明された内容をもう一度聞く｜話を聞いていない印象になる
- ng5: 「はい/いいえ」で終わる質問ばかりする｜会話が広がらず関心の深さを示せない
- ng6: 自信のなさが透ける質問（「未経験でもやっていけますか？」）｜「〜のために何を準備すべきか」の前向き形に変換する
- ng7: 相手の立場に合わない質問（役員に業務フロー詳細、現場に経営戦略）｜相手が答えられず配慮不足に見える
- ng8: 受け身すぎる質問（「すべて教えていただけるのでしょうか？」）｜主体性がない印象になる
- ng9: 面接官のプライベートに踏み込む｜距離感のない人物と見られる
- ng10: 逆質問を延々と続ける｜残り時間を見て2〜3問に絞る

### 言いにくい話題の言い換え集（s1〜s10・プレミアム）

各項目は `{ topic, phrase, why }`：

- s1: 残業｜「皆さまが最もお忙しい時期はいつ頃で、その時期はどのような働き方になるのでしょうか？」｜繁忙期の実態から逆算する定番の言い換え
- s2: 残業｜「限られた時間で成果を出す働き方をしたいと考えておりますが、業務効率化のためにどのような取り組みをされていますか？」｜生産性志向のアピールに変換
- s3: 給与｜「評価制度について教えてください。成果はどのような形で処遇に反映されるのでしょうか？」｜金額でなく仕組みを聞くと角が立たない
- s4: 給与｜「中途入社の場合、給与や等級はどのような基準で決定されるのでしょうか？」｜聞くなら基準を問う形。金額交渉は内定後の条件面談で
- s5: 離職率｜「長く活躍されている社員の方に共通する特徴はありますでしょうか？」｜定着している人の像から実態を推し量る
- s6: 離職率｜「中途入社の方の定着状況や、入社後のフォロー体制について教えていただけますか？」｜『辞める人』でなく『定着支援』に焦点を当てる
- s7: リモート可否｜「チームの皆さまは、出社とリモートをどのように使い分けていらっしゃいますか？」｜可否の白黒でなく運用実態を聞く
- s8: リモート可否｜「働き方の制度は、実際にはどのような制度を活用されている方が多いのでしょうか？」｜制度の形骸化までわかる
- s9: 休暇｜「メリハリをつけて長く貢献したいと考えておりますが、皆さまはどのようにリフレッシュされていますか？」｜長期貢献の意思とセットにする
- s10: 共通テクニック｜条件系は (1)前向きな理由を先に一言 (2)最後に1問だけ (3)聞く相手は人事を選ぶ｜3点セットで角が立たない

## C. 画面仕様（4タブ）

### 1. 質問リスト
- カテゴリA〜Eをアコーディオン表示。質問をタップで開く: 質問文＋狙い＋「☆カンペに入れる」＋「コピー」
- 無料ユーザー: B/C/D はタイトルのみ見え、タップでペイウォール（婚活デートメモの Topics ロック方式を流用）
- リスト末尾に「⚠ NG集」「🗣 言いにくい話題の言い換え」セクション（無料は各2件＋ロック導線）

### 2. ガチャ
- 段階を選んで引く: 「一次」「二次」「最終」「おまかせ」→ 3問排出 → その場で☆
- 無料は無料カテゴリ（12問）からのみ排出。排出結果の下に「プレミアムなら残り20問も出ます」導線
- チェック済み（使用済み）質問は排出から除く。全部使い切ったら「全部引き切りました🎉」

### 3. カンペ
- 上部: 自由メモ1欄（会社名・これだけは聞くこと）
- ☆した質問を段階別に一覧表示。面接直前に1画面で確認する用途。並び替え（長押しドラッグ）
- 使った質問に「✓使った」を付けると次のガチャ・カンペから薄くなる

### 4. 設定
- プレミアム購入（買い切り・非消耗型）・購入の復元・プライバシーポリシー・利用規約リンク

## F. 動作確認（Expo Go でOK、IAPはスタブ）

1. 5カテゴリ32問が出る。無料状態で A/E が開け、B/C/D はロック→タップでペイウォール
2. ガチャ「おまかせ」→無料12問から3問。☆→カンペに反映
3. カンペで並び替え・✓使った→ガチャの排出から消える
4. アプリ再起動→☆・✓・メモが残っている
5. 開発フラグでプレミアム化→B/C/D・NG集・言い換え集が全開放
6. **開発フラグを必ず戻す**
