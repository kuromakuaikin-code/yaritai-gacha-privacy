# STEEL VANGUARD ― 鋼鉄ノ戦域

『フロントミッションシリーズ ガンハザード』にインスパイアされた、オリジナルの 16bit 風・横スクロールメカアクションです。大型機兵 AW-07C〈ヴァルチャー〉を操り、黄昏の占領都市を単機で強行突破し、最深部の重装機兵〈ヴォルクグリフ〉を撃破します。

## 遊び方

`index.html` をブラウザで開くだけで動きます (ビルド・外部依存なし、単一ファイル)。スマートフォンではタッチボタンが表示されます。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | ← → / A D |
| ジャンプ (長押しでホバリング、EN 消費) | X / K / Space |
| バルカン | Z / J |
| ホーミングミサイル (残弾制) | C / L |
| 向き固定 (後退しながら射撃) | Shift |
| 照準 上 / 下 (下は空中のみ) | ↑ ↓ |
| ポーズ / サウンド切替 / リスタート | P / M / R |

## ゲーム要素

- HP と EN の 2 ゲージ制。ホバリングで EN を消費し、地上で自動回復
- 敵 6 種: 歩行機兵 / 固定砲台 / 偵察ドローン / 戦車 (曲射砲) / 攻撃ヘリ / 補給コンテナ
- 補給アイテム: HP 回復・ミサイル補給・スコア
- ボス戦: ガトリング / ホーミングミサイル (バルカンで迎撃可) / 突進 / 迫撃砲 / レーザー (体力 45% 以下で第 2 形態)
- スコア + タイムボーナス + 残 HP ボーナスで S〜C のランク評価、ハイスコアは端末に保存
- BGM / 効果音は WebAudio によるプロシージャル生成 (M でミュート)

## 実装メモ

- 480×270 の低解像度キャンバスを整数倍拡大 + スキャンラインで 16bit 風の質感に
- 依存ライブラリなし。描画は全て Canvas 2D、音は全て WebAudio で生成
- 60fps 固定ステップのゲームループ (描画は requestAnimationFrame)
