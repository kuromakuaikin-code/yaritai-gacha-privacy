# 東海おでかけナビ 運用手順

盆踊りナビの姉妹サイト。**盆踊りが終わる8月中旬から翌年6月までの空白を埋めるため**に作った。

## なぜ作ったか

盆踊りナビは価値のあるデータ収集パイプラインを持っているのに、年の10か月間そのパイプラインが遊んでいた。
紅葉（10〜12月）とイルミネーション（10月〜翌5月）を足すと年間の切れ目がほぼ消える。

さらに重要な性質として、**紅葉スポットとイルミネーション会場は毎年ほぼ同じ**。
盆踊りのように毎年データを作り直す必要がなく、運用コストが盆踊りナビよりはるかに低い。

## データを更新する

1. `spots.json` を編集
2. `cd odekake && python3 build.py`
3. コミット

`build.py` は `s/<id>.html` を生成し、`spots.json` から消したスポットのページを自動で削除する。
実行すると **要確認リスト**が標準出力に出るので、シーズン前の確認作業はこれを使う。

## spots.json の書き方

### 期間の2系統（ここが盆踊りナビとの一番の違い）

| 種類 | 使うフィールド | 用途 |
|---|---|---|
| 毎年繰り返す | `seasonFrom` / `seasonTo`（`MM-DD`） | 紅葉の見頃。**年をまたいでも書き換え不要** |
| 実日付が決まっている | `dateFrom` / `dateTo`（`YYYY-MM-DD`） | イルミネーションの開催期間。毎年更新が必要 |

`seasonTo` が `seasonFrom` より前なら、年をまたぐ期間として扱われる。
表示用の文言は `seasonNote` に日本語で書く（これが画面に出る）。

### verifyStatus

| 値 | 意味 | 画面表示 |
|---|---|---|
| `confirmed` | 今シーズンの日程を公式サイトで確認済み | バッジなし |
| `要確認` | 会場は確かだが、今年の日程・料金は未確認 | 赤い「日程は要確認」バッジ＋注意書き |

**紅葉の見頃（例年の目安）は安定情報なので `要確認` のままでよい。**
`要確認` を外すのは、その年のライトアップ日程・料金を公式サイトで確認したときだけ。

### 必須フィールド

`id` / `genre`（`koyo` または `illumi`）/ `name` / `prefecture` / `city` / `seasonNote` /
`source` / `sourceName` / `lastVerified` / `verifyStatus`

`id` の重複と未知の `genre` は `build.py` がエラーで止める。

### 座標について

`lat` / `lng` は「現在地から近い順」の並べ替えだけに使っている。
おおよその値で用は足りるが、**経路案内には使っていない**（地図リンクは名前と住所で検索する形）。
新しいスポットを足すときは地図で確認した値を入れること。

## 掲載ルール

盆踊りナビと同じ方針に従う。

- 情報元のページを**転載しない**。事実（会場・例年の見頃・ライトアップの有無）だけを書く
- `source` には実際に確認したページの URL を入れる。確認していないものは載せない
- 見頃はその年の気候で前後する。断定せず「例年」と書く

## 収益化の設定箇所

現在どちらも未設定。設定するとその場で有効になる。

| 場所 | ファイル | 変数 |
|---|---|---|
| AdSense | `index.html` | `const ADSENSE = { client: "", slot: "" }` |
| 寄付 | `../bon-odori/support.html` | `const DONATE_URL = ""` |

`ADSENSE` は両方が空のとき広告枠そのものを出さないので、空のまま公開しても崩れない。

## sitemap

`site-config.json` の `publicBaseUrl` が空の間は sitemap を生成しない（盆踊りナビと同じ挙動）。
独自ドメインまたは GitHub Pages の URL を入れると、次回ビルドから生成される。

## 今後足す候補

年間の空白をさらに埋めるなら、この順で効く。

1. **桜**（3月下旬〜4月上旬）— 会場固定、検索需要が紅葉と同等以上
2. **あじさい**（6月）— 6月の空白を埋める
3. **芝桜・ネモフィラ**（4〜5月）

いずれも「会場が毎年同じ」性質を持つので、運用コストが増えない。
逆に、花火大会は日程が毎年変わるうえ盆踊りと同時期なので、優先度は低い。
