# EDM ダンス動画スタイル プロンプト

AI 動画生成用のスタイルプリセット。EDM / テックハウスのパーティーで、手持ちカメラ (魚眼) が音楽に合わせて揺れながら、ダンサーを捉える映像。画風は伝統画材風のセミスケッチで、線や塗りが常時ちらつく (boiled lines) アニメーション。

踊り手のキャラクター設定:

1. [edm-dance-video-character.md](edm-dance-video-character.md) — 星の魔女っ子 (チビ体型、三面図つき)
2. [edm-dance-video-character-2.md](edm-dance-video-character-2.md) — 紅ドレスのツインテール (通常頭身)

2 人同時出演は [edm-dance-video-duo.md](edm-dance-video-duo.md) (2girls 構成、頭身統一の 2 案)。

## タグ分類

### 一貫性

| タグ | 意図 |
| --- | --- |
| unchanging style | カット間でスタイルを変えない |
| perfect visual consistency | キャラ・色味の完全な一貫性 |

### 画風 (フリッカー系スケッチ)

| タグ | 意図 |
| --- | --- |
| flickering jittering line art | 線画がフレームごとに揺らぐ (boiled lines) |
| flickering jittery hatch shading | ハッチング陰影のちらつき |
| flickering jittering art medium | 画材の質感自体が揺らぐ |
| flickering jittering paint stroke texture | 筆致テクスチャのちらつき |
| traditional art medium | 伝統画材 (アナログ) 風 |
| semi sketchy style | 描き込みすぎないセミスケッチ調 |

### カメラ

| タグ | 意図 |
| --- | --- |
| handheld camera / shaky camera / unstable camera | 手持ちの不安定な揺れ |
| camera rocks side to side | 左右にロッキング |
| fisheye lens / fisheye lens camera moves up and down and in regularly | 魚眼で上下＋前進をビートに合わせて反復 |
| camera orbits back and forth | 被写体の周りを行き来するオービット |
| fingers trace body camera follows her hands | 体をなぞる指先をカメラが追従 |
| foreshortening | 広角の遠近強調 (パース圧縮) |

### ダンス・モーション

| タグ | 意図 |
| --- | --- |
| limited animation | コマ数を抑えたリミテッドアニメ |
| bouncing | ビートに合わせた上下バウンス |
| hand dancing / shimmying / hands go up | ハンドダンス、肩振り、両手を上げる |
| fluid graceful and elegant flowing motion | 流麗でエレガントな連続動作 |
| momentary gesture at the viewer | 一瞬だけ視聴者へ向けるジェスチャー |
| feeling the music / mostly dancing / non verbal | 台詞なし、音に浸って踊り続ける |
| djing | DJ プレイのカット |
| dynamic / windy | 動きの勢い、風になびく髪・服 |
